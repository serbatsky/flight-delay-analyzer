# ✈️ Flight Delay Analyzer

Analysis of flight delays using Python and Pandas.

## What this project does
- Analyzes average delay per airline
- Identifies most common delay reasons
- Compares cancellation rates across airlines

## 📊 Key Insights

- Weather and air traffic are among the most frequent delay causes  
- Certain airlines show consistently higher average delays  
- Cancellation rates vary significantly between airlines  

## Technologies
Python · Pandas · Matplotlib · NumPy
